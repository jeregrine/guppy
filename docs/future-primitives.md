# Future primitives

These are deferred primitive ideas, not active commitments. Guppy is currently in stabilization/maintenance mode; new surface area should be driven by concrete examples, tests, and GPUI 0.2.2 compatibility.

Higher-value gaps to revisit later:

- editor parity and advanced text layout beyond current rich text runs/highlights
- richer popover/select overlay lifecycle, positioning, and nested overlay semantics
- data-table/tree keyboard, focus, and virtualization hardening beyond the first-pass primitives
- richer canvas commands such as paths, text, images, and fine-grained hit testing
- element-local menu/context-menu polish

Keep implementation notes and current compatibility status in `docs/gpui-compliance.md`; move items here only when they are deliberately deferred.
